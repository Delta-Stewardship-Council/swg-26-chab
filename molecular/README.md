# 📁 molecular/

This folder contains workflows, code, and data related to the molecular data synthesized in this project.

⚠️ **Notice:** The files in this directory are active working versions for internal organization only. They are subject to change and should not be used for external analyses.

---

## 🗂️ Subfolder Structure

* ### 🌐 `genomics/`
  Workflows, code, and data related to shotgun sequencing of environmental samples.

* ### 🧬 `metabarcoding/`
  Workflows, code, and data related to eDNA metabarcoding of environmental samples.

* ### 🧮 `qpcr/`
  Workflows, code, and data related to quantitative PCR (qPCR) targeted assays for HAB species and toxin genes in environmental samples.
